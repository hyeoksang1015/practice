[ ABOUT WEBMATE ]

기획부터 개발까지,
한 사람이 끝까지 책임집니다.

웹메이트는 브랜드 홈페이지, 반응형 랜딩페이지, 맞춤형 웹 서비스를 만드는 웹 제작 스튜디오입니다. 기획·디자인·개발을 나눠 맡기지 않고 하나의 흐름으로 이어서 작업합니다.

02DESIGN

UI/UX 디자인

과한 장식 없이 읽기 쉬운 글꼴과 그리드로 신뢰감을 만듭니다.

03FRONTEND

퍼블리싱 · 프론트엔드

어떤 기기에서도 깨지지 않는 반응형 화면을 웹 표준으로 구현합니다.

04BACKEND

백엔드 · 풀스택

회원가입, 데이터베이스, 결제, 관리자 화면까지 실제 기능을 붙입니다.

  • 가지고 있는 디자인 시안을 실제 웹으로 옮기고 싶은 분

[ PROCESS ]

단계마다 확인하며
함께 완성합니다.

각 단계의 결과물을 보여 드리고, 확인을 받은 뒤 다음 단계로 넘어갑니다.

  1. 01
    PHASE 01

    상담 · 기획

    목적, 대상 고객, 필요한 기능, 예산과 오픈 일정을 듣고 작업 범위를 정합니다.

    → 요구사항 정리
  2. 02
    PHASE 02

    구조 설계 · 디자인

    페이지 구성과 동선을 잡고, 분위기에 맞는 디자인 시안을 만들어 검토받습니다.

    → 와이어프레임 · 디자인 시안
  3. 03
    PHASE 03

    개발 · 구현

    확정된 시안으로 반응형 화면을 만들고, 필요한 기능과 데이터를 연결합니다.

    → 테스트 주소에서 미리 확인
  4. 04
    PHASE 04

    검수 · 전달

    기기별 화면, 링크, 폼 동작을 점검한 뒤 도메인을 연결하고 소스코드를 전달합니다.

    → 오픈 · 인수인계

  2. 마음에 드는 참고 사이트 1~3곳
  3. 로고 · 사진 · 소개 문구 등 준비된 자료
  4. 원하는 오픈 일정과 꼭 필요한 기능
