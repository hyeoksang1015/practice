[ 01. SPATIAL CHIAROSCURO ]

더 서울라이티움(THE SEOULITEUM)은 서울숲의 유기적 생명력과 성수동의 인더스트리얼 헤리티지가 교차하는 지점에 구축된 4,800㎡ 규모의 조형적 문화예술 성소입니다.

architecture Spatial Philosophy

“빛이 존재하기 위해 어둠이 선행하듯, 온전한 몰입은 비워진 보이드(Void)에서 출발한다.” — Curatorial Board Manifesto

빛과 그림자의 극적인 대비(Chiaroscuro)를 공간 문법으로 차용하여, 관람객이 경계를 넘어서는 순간 도심의 소음은 소거되고 전위적 예술과 오롯이 독대하는 경험을 선사합니다. 8.5미터에 달하는 무주(Column-free) 구조의 천장고는 작가의 창작적 스케일을 한계 없이 투영합니다.

Void Volume Index • 92.4%

자연광이 절제된 암실의 순수성과 아트리움의 유연한 투광성은 현대 미술, 오뜨 꾸뛰르 패션 프리젠테이션, 미디어 인스톨레이션, 그리고 글로벌 브랜드의 헤리티지 서사를 담아내는 정교한 무대가 됩니다.
