## Brand & Style

This design system establishes an elite, architectural aesthetic crafted for executive-level B2B tech decision-makers and senior engineering leadership. It balances high-velocity MLOps precision with high-end enterprise consultancy authority.

### Core Character & Mood
- **Atmospheric Obsidian:** Deep, rich dark-mode surfaces inspired by deep space, high-performance computing clusters, and midnight slate.
- **Architectural Rigor:** Deliberate micro-alignments, measured hierarchy, and hairline dividers create an immediate sense of operational stability and precision.
- **Controlled Luminescence:** Restrained electric blue and subtle cyan atmospheric highlights imply cutting-edge AI computation without visual noise.

### Style Direction
A disciplined synthesis of **Minimalism** and **Refined Glassmorphism**. Dark slate containers leverage ultra-fine translucent borders (`rgba(255, 255, 255, 0.08)`), low-opacity surface fills, and deliberate negative space to showcase sophisticated technical depth, technical benchmarks, and enterprise solutions.

## Colors

The palette is engineered around deep obsidian foundations layered with electric energy, mirroring modern machine learning compute infrastructure.

### Functional Roles
- **Primary (`#3B82F6`):** Electric Cobalt. Drives primary CTAs, active operational indicators, focused tab states, and pivotal benchmark accents.
- **Secondary (`#06B6D4`):** Cyan Luminescence. Reserved for AI pipeline nodes, inference metric callouts, and subtle ambient gradients that denote high-level machine learning capability.
- **Tertiary (`#1E293B`):** Deep Slate Container. The foundational fill for cards, elevated code blocks, and structural surfaces.
- **Neutral Base (`#0B0F19`):** Midnight Obsidian canvas. Deep, low-reflection tone optimizing contrast and eliminating ocular fatigue.

### Surface Tiers
- **Canvas Base:** `#0B0F19`
- **Surface Elevation 1 (Cards, Modules):** `#0F172A` at `80%` opacity with backdrop blur.
- **Surface Elevation 2 (Dropdowns, Overlays, Active Panels):** `#1E293B` at `95%` opacity.
- **Hairline Borders:** `rgba(255, 255, 255, 0.08)` for dormant states; `rgba(59, 130, 246, 0.35)` for focused or hover states.

## Typography

The type system creates sharp contrast between geometric, executive-facing headings and surgical, monoline body copy.

- **Headlines (Manrope):** Geometric, solid, and modern. Conveys corporate stability and technical confidence across executive summaries and key value props.
- **Body & Data (Geist):** Clean, neutral, high-density monospace-adjacent aesthetic. Ensures dense architectural diagrams, telemetry metrics, and consulting deliverables remain legible at any scale.

### Composition Guidelines
- Pair heavy `Manrope` headings with muted `Geist` subtext (`#94A3B8`) to establish immediate reading cadence.
- Ensure all technical KPI units, status tickers, and telemetry data utilize uppercase `label-md` with slight positive tracking.

## Layout & Spacing

Layouts follow a strict 12-column mathematical grid on desktop and a 4-column structure on mobile devices, emphasizing architectural cadence and ample breathing room.

### Responsive Breakpoints
- **Desktop (1280px+):** 12-column fluid grid, `margin`: 3rem (max width container: 1360px), `gutter`: 1.5rem.
- **Tablet (768px - 1279px):** 8-column layout, `margin`: 2rem, `gutter`: 1.25rem.
- **Mobile (< 768px):** 4-column fluid layout, `margin-mobile`: 1.25rem, `gutter-mobile`: 1rem.

### Spatial Rhythm
- High-level sections (e.g., Hero, Service Matrix, Case Studies) breathe with `space-xl` and higher multipliers (4rem to 6rem vertical separation).
- Structural components leverage `space-md` for internal component clearance and `space-sm` for related label-input stacks.

## Elevation & Depth

Visual hierarchy is maintained through layered translucency, subtle edge luminance, and deep dark-space shadows rather than high-contrast surfaces.

### Surface Tiers
- **Tier 0 (Canvas):** Pure `#0B0F19`, absorbing light and providing an uncompromising backdrop.
- **Tier 1 (Base Cards & Shells):** Semi-transparent `#0F172A` with `12px` backdrop blur and a `1px` outer hairline of `rgba(255, 255, 255, 0.07)`.
- **Tier 2 (Popovers, Flyouts & Floating Nav):** `#1E293B` at `90%` opacity, `16px` backdrop blur, bound by `rgba(59, 130, 246, 0.2)` edge reflection.

### Glows & Luminescence
- **AI Core Glow:** Use radial gradients (`radial-gradient(circle, rgba(59, 130, 246, 0.15) 0%, transparent 70%)`) placed underneath primary interactive components or architectural diagrams to signify active computation.
- **Shadow Profile:** Soft, deep drops: `0 20px 40px -15px rgba(0, 0, 0, 0.7)`.

## Shapes

The shape system adopts a disciplined **Soft (1)** geometry:
- Base elements (buttons, inputs, status tags): `0.25rem` (4px).
- Structural containers (cards, data tables, code modules): `0.5rem` (8px).
- Dialogs, modal shells, and hero interaction pods: `0.75rem` (12px).

This sharp, low-radius styling reinforces high-engineering precision, evoking silicon chips, terminal windows, and enterprise server rack configurations.

## Components

### Buttons
- **Primary:** Background `#3B82F6`, text `#FFFFFF`, border `1px solid rgba(255, 255, 255, 0.2)`, `roundedness: 1`. Hover transitions to `#2563EB` with a `0 0 16px rgba(59, 130, 246, 0.4)` aura.
- **Secondary / Ghost:** Background `rgba(15, 23, 42, 0.6)`, text `#E2E8F0`, border `1px solid rgba(255, 255, 255, 0.1)`. On hover, border illuminates to `rgba(59, 130, 246, 0.5)`.

### Cards & Glassmorphism Modules
- Built on `#0F172A` with a subtle linear gradient fading into `#0B0F19`.
- Hairline top border highlight: `linear-gradient(90deg, rgba(59, 130, 246, 0.4), rgba(6, 182, 212, 0.1), transparent)`.
- Padding: `space-lg` (1.5rem) on desktop; `space-md` (1rem) on mobile.

### Badges & Chips
- Status indicators (e.g., "MLOps Verified", "Cluster Active") employ a pill structure (`rounded-full`), `rgba(59, 130, 246, 0.1)` surface, and a `1px solid rgba(59, 130, 246, 0.3)` border with a glowing `4px` live status dot.

### Inputs & Form Fields
- Background `rgba(11, 15, 25, 0.8)`, border `1px solid rgba(255, 255, 255, 0.12)`, text `#F8FAFC`.
- Focus state: Border transitions to `#3B82F6` accompanied by an outer `0 0 0 1px #3B82F6` ring.

### Data Metric Callouts & Telemetry Blocks
- Monospace styling for integers and telemetry readouts.
- High-contrast value text (`#F8FAFC`) supported by low-contrast sublabels (`#64748B`).
